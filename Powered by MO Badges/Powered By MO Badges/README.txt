METHOD OPTIMIZATION — ATTRIBUTION BADGES
=========================================

badge-snippets.html   Open in a browser. Three badge treatments (minimal, inline
                      pill, card) x light/dark, each with a copy-paste HTML
                      snippet and a live preview. Snippets are self-contained:
                      inline SVG mark + live text, nothing to upload.

mo-mark.svg           MO monogram, navy (#16243A). 103x54 units.
mo-mark-white.svg     MO monogram, reversed for dark backgrounds.
mo-lockup.svg         Full lockup: monogram + METHOD OPTIMIZATION, navy.
mo-lockup-white.svg   Full lockup, reversed.
mo-lockup.png         Original raster lockup (303x79, transparent).

USAGE
- Minimum mark width 20px; minimum lockup width 120px.
- Clear space: keep at least half the mark's height clear on all sides.
- On dark footers use the white files, or change color:#16243a to #ffffff in a
  snippet - the mark and divider follow currentColor.
- Do not recolor, outline, stretch, or add effects to the mark.
- Lockup SVGs set type in Helvetica/Arial. If your brand font differs, use
  mo-mark.svg plus live text (the snippets do this) so type matches the site.
